# Admin Navigation Wireframe Notes

```
┌────────────────────────────┐
│ Admin Navigation           │
├────────────────────────────┤
│ Dashboard Overview         │
│ Community Management       │
│ User Directory             │
│ Analytics ★ NEW            │
│ Billing                    │
│ Settings                   │
└────────────────────────────┘
```

- **Placement:** Analytics sits beneath "User Directory" to emphasise monitoring after operations.
- **Iconography:** Heroicons `ChartBarSquareIcon` 24px with `text-sky-500` fill.
- **Hover/Active States:** `bg-slate-100` background, left border accent `border-l-4 border-sky-500`.
- **Mobile Drawer:** Analytics entry uses same order, ensure VoiceOver reads "Analytics, new" for first release.
